# Joker of Academics LaTeX Template

Joker of Academics 官方 LaTeX 模板，提供中文与英文两个独立版本。

## Templates

- `Joker_of_Academics_latex_template_CN/`：中文模板。
- `Joker_of_Academics_latex_template_EN/`：英文模板。

每个目录保留源文件、参考文献文件、模板资源与编译后的 PDF 预览；LaTeX 中间构建产物不进入版本库。

## Build

在对应模板目录中使用 XeLaTeX / LaTeX 工具链编译 `document.tex`。具体字体与宏包以模板源文件为准。
